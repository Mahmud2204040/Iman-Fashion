# Iman Fashion

A mobile-responsive clothing-shop management application serving business operations, offline-ready caching, order tracking, and ledger reconciliation.

## Tech Stack
* **Frontend:** React 18, Vite 5, TanStack Query, IndexedDB.
* **Backend:** Node.js, Express 5, Prisma 7, PostgreSQL.
* **Architecture:** Multi-layered API response caching (L1-L5). Docker integrations, Vercel frontend edge deployment.

## Repository Status
All major development milestones M0 through M6 are **complete**, including external UI integration, API data services, complex real-time invalidation caching, and Docker pipelines.
